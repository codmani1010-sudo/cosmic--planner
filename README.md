# Cosmic Planner V1

نسخه‌ی اولیه‌ی وب‌اپ پلنر کهکشانی.

## قابلیت‌ها
- داشبورد
- اهداف و درصد پیشرفت
- درس و مطالعه
- برنامه روزانه
- عادت‌ها
- صفحه پیشرفت
- تقویم داخلی
- تنظیم نام
- ذخیره خودکار اطلاعات در LocalStorage
- طراحی Responsive برای موبایل
- PWA manifest برای قابلیت نصب به Home Screen

## اجرا
فایل‌ها را روی یک هاست استاتیک قرار بده و `index.html` را باز کن.
برای PWA کامل، بهتر است سایت روی HTTPS باشد.

## مرحله بعد
Google Calendar را می‌توان با OAuth و Google Calendar API اضافه کرد تا رویدادهای زمان‌دار به حساب کاربر منتقل شوند.
